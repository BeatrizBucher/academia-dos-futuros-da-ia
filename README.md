# Academia dos Futuros da IA

Quiz interativo, responsivo e estático sobre impactos da inteligência artificial.

## Publicar com GitHub Pages

1. Envie os arquivos do site para a raiz deste repositório.
2. Abra **Settings → Pages**.
3. Escolha **Deploy from a branch**, branch `main` e pasta `/(root)`.
4. Salve e aguarde o GitHub publicar o endereço do site.

O projeto não usa banco de dados nem coleta dados pessoais.
